# SeoulMate 코스 다양성 설계와 검증

## 문제

DB의 데이터셋 quota는 후보 원천의 편중을 줄이지만 최종 코스의 다양성을 보장하지 않는다. 기존 variant 생성기는 이미 사용한 장소를 전역에서 강하게 제외해 장소 중복은 없었지만, 후보가 부족하면 코스 자체를 버렸다. 10개 지역 실측에서 요청당 평균 variant는 2.9개였다.

## 개선 결과

동일한 10개 지역·예산·시간·분위기 조건에서 측정했다.

| 지표                  | 개선 전 | 개선 후 |            변화 |
| --------------------- | ------: | ------: | --------------: |
| 평균 variant 수       |   2.9개 |   3.9개 | **34.48% 증가** |
| 4개 variant 제공 지역 |    0/10 |    9/10 |   **90%p 증가** |
| 평균 category entropy |  1.6552 |  1.6928 |  **2.27% 증가** |
| 평균 category 종류    |   3.5개 |   3.6개 |  **2.86% 증가** |
| 전체 고유 장소 비율   |    100% |  98.33% |     1.67%p 감소 |
| 평균 코스 간 Jaccard  |       0 |  0.0111 |  낮은 중복 유지 |
| 예산 준수율           |  미측정 |    100% |  제약 유지 확인 |
| 시간 준수율           |  미측정 |    100% |  제약 유지 확인 |

개선 후 더 많은 코스를 생성하기 때문에 고유 장소 비율은 소폭 낮아졌다. 그러나 평균 Jaccard 0.0111로 코스 쌍의 장소 중복은 매우 낮다. 후보가 6개뿐인 망원은 중복 코스를 억지로 채우지 않고 3개만 반환한다.

원본은 [`diversity-before.json`](../reports/benchmark/diversity-before.json)과 [`diversity-after.json`](../reports/benchmark/diversity-after.json)에 있다.

## MMR 장소 선택

각 역할에 맞는 후보 중 단순 최고점 한 개를 고르는 대신 적합도와 기존 선택 장소와의 비유사도를 함께 계산한다.

```text
MMR(place)
  = λ × relevance
  - (1 - λ) × max semanticSimilarity(place, selected)
  + variantObjectiveBonus
```

의미 유사도는 같은 역할 0.35, 같은 데이터셋 0.15, 같은 가격 구간 0.15, 같은 실내·실외 속성 0.15, 500m 이내 0.20 또는 1.2km 이내 0.10을 합산한다.

`best`는 적합도 비중을 0.78로 유지한다. `balanced`는 λ를 0.52로 낮춰 의미적 novelty를 더 강하게 반영하고, 나머지 variant는 0.64를 사용한다.

## Variant별 목적함수

| Variant      | 우선 조건                                        |
| ------------ | ------------------------------------------------ |
| `best`       | 기존 종합 추천 점수                              |
| `balanced`   | 역할·데이터셋·가격·실내외 비유사성과 가까운 동선 |
| `indoor`     | 실내 후보만 허용하고 실내 objective bonus 적용   |
| `low-budget` | 예상비용이 낮은 장소와 전체 예산 85% 목표        |
| `mood-*`     | 분위기 keyword affinity bonus                    |

분위기가 입력돼도 mood variant만 반환하지 않는다. mood variant 뒤에 `best`, `balanced`, `indoor`, `low-budget`을 중복 없이 채워 최대 4개의 서로 다른 목적을 시도한다.

## 코스 간 중복 정책

기존에는 새 코스의 장소가 과거 모든 코스에서 한 번이라도 쓰였는지를 합산해 50% 이상이면 폐기했다. 개선 후에는 각 기존 코스와 신규 코스를 쌍별 Jaccard로 비교한다.

```text
J(A, B) = |A ∩ B| / |A ∪ B|
```

어느 한 코스와 Jaccard가 0.5 이상이면 폐기한다. 후보가 부족해 전역 미사용 장소만으로 코스를 만들 수 없으면 기존 장소를 허용하되 MMR에 재노출 penalty 0.4를 적용한다.

## 재현

```powershell
$env:BENCHMARK_LABEL = "diversity-after"
npm run benchmark:diversity
```

외부 provider key를 비운 로컬 PostgreSQL 조건이며 HTTP·인증·저장 latency는 포함하지 않는다.

## 한계와 다음 지표

- 10개 지역의 회귀 표본이며 실제 사용자 만족도를 직접 의미하지 않는다.
- category entropy는 역할 분산을 나타내지만 코스의 주관적 매력을 보장하지 않는다.
- 운영에서는 코스 선택률, 저장률, 장소 클릭률, 완주율과 반복 추천 이탈률을 함께 측정해야 한다.
- 후보가 매우 적은 지역은 다양성보다 실재성·예산·시간 제약을 우선하므로 4개 미만을 반환할 수 있다.
